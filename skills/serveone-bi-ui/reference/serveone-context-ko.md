# 서브원 조직·도메인 맥락 (serveone-bi-ui 참조)

> 화면·코드·문서 작업 시 이 맥락을 전제로 한다. 컬러·차트·타이포 규약 본문은 `../SKILL.md`.

## 조직

서브원(ServeOne) CTO 조직 산하 Data/AI 팀이 소유하는 코드베이스다.
데이터 분석, 예측 모델링, AI 툴링, 데이터 플랫폼 인프라를 담당하며
전략구매·경영기획·영업·IT 조직과 협업한다.

의사소통은 한국어가 기본이고 기술 용어는 영어를 그대로 쓴다.
커밋 메시지, 코드 주석, 변수명은 영어. UI 문구와 문서는 한국어.

## 사용자 — 의사결정 3계층

이 화면을 쓰는 사람은 일반 소비자가 아니라 **하루 종일 같은 화면을 보는 사내 현업 담당자**다.
학습 비용을 한 번 치르고 나면 밀도와 속도를 원한다.
온보딩 친화적 설계보다 스캔 속도와 정보 밀도를 우선한다.

| 대상 | grain | 화면 성격 |
|---|---|---|
| 현업 담당자 | 품목·거래처 행 단위 | 예외 탐지, 액션 시작점 |
| 팀장 | 품목군·조직 단위 집계 | 추세와 편차 |
| 경영층 | 전사·사업부 단위 | 단일 지표 + 기준선, 요약 |

## 도메인 용어

코드·UI·문서에서 아래 용어를 임의로 번역하거나 풀어쓰지 않는다.

- **전가율** — 매입가 인상분이 매출가에 반영된 비율. 핵심 수익성 지표.
- **GP Impact** — 전가 실패가 매출총이익에 미친 금액 영향.
- **매입가 반영억제** — 매입가 인상을 매출가에 반영하지 않고 흡수하는 상태.
- **CI** — 서브원 코퍼레이트 아이덴티티. 데이터 컬러와 구분한다(SKILL.md §4).
- **매입가 / 매출원가** — 서로 다른 개념이다. 화면 레이블에서 혼용 금지.
- **순액 조정** — 총액이 아닌 순액 기준 회계 처리.
- **직송 / 무재고 / 센터 / VMI** — 배송 유형 분류. P/O 연결과 재고 소유 주체가 다르다.

```
협업        Confluence, Slack
사내 플랫폼  SSP, S-MRO, G-lab
```

## 아키텍처 원칙

- 데이터 조회와 집계는 **Server Component에서 끝낸다.** Client Component에는 직렬화된
  결과와 차트만 내린다.
- `'use client'` 경계는 차트·인터랙션 컴포넌트 파일 최상단에만 둔다. 페이지는 서버로 유지한다.
- Redshift 쿼리를 클라이언트에서 직접 호출하지 않는다. 반드시 서버 라우트 또는
  Data MCP를 경유한다.
- 대시보드 grain은 쿼리 레벨에서 확정한다. 클라이언트에서 재집계하지 않는다.
